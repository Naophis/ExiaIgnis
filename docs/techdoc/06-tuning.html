CHAPTER 6

調整手順

テストモード (system.yaml の mode、user_mode != 0 で起動) の一覧と、新しい機体や足回り変更後に踏む調整の順序です。Astraea の tuning.md を ExiaIgnis の機能に合わせて更新しました。

6.1 テストモード一覧

本走行 (user_mode: 0) ではタイヤをダイヤル代わりに番号を選び、長押しで決定します: 0 全探索 / 1 片側・帰還探索 / 2〜N+1 最短走行 (exec.json の各行) / N+2 その場旋回 / N+3 吸引テスト / N+4 全プロファイルのタイム計算 / N+5 迷路データ消去。

6.2 調整の順序

A. 基本機能の確認

  1. UI: ボタン (GPIO2)、LED (I2C)、ブザー (PWM)。起動音が鳴り、モード番号が LED に出ること。
  2. ADC: バッテリー電圧 (battery_gain をテスターと合わせる)、壁センサー 4 ch の暗値と点灯値 (mode 14)。
  3. PSRAM: 起動ログの rw_test が PASS であること。FAIL ならログは取れない。
  4. 駆動モーター: motor_debug_mode で左右の回転方向 (motor_r/l_cw_ccw_type)。タイヤを浮かせて低 duty で確認。
  5. 吸引: mode 11 でランプと保持。ESC の方向が逆なら mode 27。ロジックアナライザで GPIO11 の DShot 波形 (idle-low、bit 1 = 75 %、フレーム周期 400 µs) を一度は見る。

B. センサー

  1. LED 整定時間: mode 14 で led_light_delay_cnt を、点灯値が上がりきる最短に。
  2. 距離校正: mode 15 で距離を変えながらダンプし、sensor.yaml の変換ゲイン (a, b) を当てはめる。
  3. 壁基準: mode 2 で片側の壁制御を切りながら中央に置いた時の左右 45° を読み、sla_wall_ref_l/r、exist しきい値を決める。

C. 同定 (足回りを触ったら必ず)

  1. タイヤ径: mode 2 でできるだけ長い距離を走らせて tire を合わせる (吸引 ON の潰れ込みで)。
  2. エンコーダ LUT: v ≈ 400 mm/s の直進を置き直しながら 8〜11 本取り、enc_lut_fit.py → enc_lut.yaml を送信。--check で適用を確認。超信地はスクラブで使えない。
  3. トレッド: tread_check.py で実効 tread と左右径差。tread を変えたら Lm も比例させる。
  4. 直進 FF: 巡航と高加速 (accl 42,500) の直進ログで ff_check.py。ratio a / v が 1.0 ± 0.05 に入るまで Mass / viscous を追う。低加速 (2500) のログは 10 % の差が 0.03 V にしかならず判定に使えない。

D. ゲイン

  1. 速度ループ (motor_pid2): mode 2 / 13。60〜200 Hz の duty RMS で判定 (基準 0.41 → 0.19 まで下げた実績)。リミットサイクルが出たら p と i を比率を保って下げる。
  2. 角速度ループ (gyro_pid): mode 3 / 20 / 21。FF 主導なので P は極小のまま、アンチワインドアップと角度差 I 項の効きを見る。
  3. 壁 PD (str_ang_pid_fast) と Kanayama: mode 2。左右から強制的にずらして開始し、ey の標準偏差 (0.6 mm 程度) と収束時間で判定。傾けて開始したときの揺れはジャイロゼロ点の問題で別扱い。

E. 探索系

  1. 前壁補正: mode 7 / 8 で front_dist_offset、左右差しきい値、終了条件。
  2. 探索スラローム: mode 5 で sla_wall_ref、normal_sla_offset_front/back。
  3. 探索の壁切れ: mode 9 (search_mode: 1) で search_wall_off_*_dist_offset、clear_dist_ragne_*。
  4. 超信地: mode 23 で前壁補正込みの反復。

F. 最短走行

  1. プロファイルの机上確認: 2.3 節の式で FF 差動 duty ≤ 58 %、横 G ≤ 9.0 G。front は wall_off_hold_dist_str の下限 (負値ぶん + 2 mm) を割らないこと。
  2. スラローム単体: mode 1 を往復 (sla_return: 1) で n ≥ 4。turn_exit_check.py の出口残差で判定し、front/back は左右同値から始める。
  3. 壁切れ → スラローム: mode 9 (search_mode: 0) / 19。柱谷検知の lag は tests/pillar_trough_host でログ再生してから実機。
  4. 速度スイープ: 同一ルートを t_1800 → t_2100 で走らせ、タイム・飽和率・壁切れ区間の距離増を比べる (8 章)。

吸引 ON/OFF で摩擦 FF の係数 (*_suction) と旋回の P ゲイン (turn_angle_fb.gain_tbl) が変わります。同定ログは吸引 ON で取ったものが主なので、吸引 OFF の値は未検証です。
