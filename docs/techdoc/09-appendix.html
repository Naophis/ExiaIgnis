A.4 用語集

用語意味
hf / clハーフサイズ / クラシックサイズ。パラメータファイルの拡張子で切り替え
tickCore1 の 1 kHz 制御周期 (1 ms)
ego_in / img_*計画側の自己伝播状態。img_ang / img_dist はセグメント内の計画角・距離
kim (x, y, theta)位置 KF から作るセグメント座標系の実測位置・向き。旋回の角度誤差の基準
odm軌道点由来のセグメント座標系オドメトリ (ログ用)
i_biasimg_ang − kim.theta。計画角と実測角の差
duty_sen壁 PD の出力。名前は duty だが角度オフセット [deg]
duty_roll / duty_cヨー (差動) と並進のフィードバック出力。トルク次元
ff_duty_rpm逆起電力ぶんの電圧 FF (Ke × ω)
kireme (切れ目)壁の切れ目。壁誤差を 0 に落とす区間のしきい値
wall_off (壁切れ)壁が切れた位置を検出して旋回位置を決めるモーション
柱の谷 (pillar trough)壁なし開始の壁切れで 45° センサーが見せる「下に凸」の形
SLA_FRONT_STR / SLA_BACK_STRスラローム前後の直線区間 (front / back オフセット)
pow_nスラロームの角加速度形状の次数。大きいほどピークが高く旋回が短い
sakiyomi (先読み)ヨー FF を数 tick 先の形状関数で作ること
turn_settle旋回の制御則を直後の直進へ引き継ぐ機構
start_align走り出し後、壁と平行になった時点で向きを再アンカーする機構
hold走行開始前の静止保持 (吸引ランプ中)
slow decay / fast decayPWM の OFF 期間にモーターを短絡 (ブレーキ) するか開放 (コースト) するか
DitherPwmPWM 周期ごとに compare 値を N / N+1 で切り替えて平均で 1 count 未満の duty を出す方式
DShotESC へのデジタルスロットル信号。本機は 600 kbps 標準 (非反転)
veneerRAM 上のコードからフラッシュ上の関数を呼ぶときにリンカが挟む中継コード
